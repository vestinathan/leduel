## 📊 **MÉTHODOLOGIE DE SCORING**

### Formule du Gap Score
```
gap_score = demand_score / (supply_score + 1)

where:
  demand_score = population × revenu_median × (trends_score / 100)
  supply_score = nb_salons × avg_rating
```

### Formule du Score Final (pour les options)
```
final_score = (gap_score × 0.6) + (accessibility_score × 0.3) + (cost_score × 0.1)

where:
  accessibility_score = 1.0 if metro_distance ≤ 200m else 0.5 if ≤ 500m else 0.0
  cost_score = 1 - (rent_cost / max_rent_cost)
```
